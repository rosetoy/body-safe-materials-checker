# Body-Safe Materials Checker

Educational body-safe materials reference for adult toys and pleasure products.

## Online demo

**https://rosetoyus.com/tools/body-safe-materials/**

## Features

- Search materials by name or by words in the notes, such as silicone, glass, or lubricant
- Filter by non-porous, porous, or blends whose porosity varies
- Body-safe context, care tips, and common uses for medical-grade / platinum silicone, ABS, TPE/TPR, PVC, jelly and unknown soft plastics, borosilicate glass, stainless steel, aluminum, and elastomer blends
- Works offline: one HTML file, no build step, no account, and no analytics or trackers
- Mobile-friendly layout you can host as a static page or open from a downloaded copy
